### Scoring Guide

- **5**: Excellent, no issues found
- **4**: Good, minor issues that don't affect correctness
- **3**: Acceptable, some issues that may affect scoring accuracy
- **2**: Problematic, significant issues that likely cause incorrect scoring
- **1**: Broken, fundamental issues that make the task unusable

### Verdict Rules

- **pass**: overall >= 4 and no dimension below 3
- **review**: overall == 3, or any dimension is 2
- **reject**: overall <= 2, or any dimension is 1, or grader has clear bugs (wrong record IDs, missing imports, unreachable checks)

### Common Issues to Watch For

1. **Grader references non-existent record IDs** — check every ID in grader.py against signal_records
2. **Grader checks for tools not in the available tools list** — the agent cannot call tools it doesn't have
3. **Prompt leaks investigation details** — the prompt should state the goal, not the steps or specific data to find
4. **Scoring weights are unreasonable** — result-type components should dominate (>= 0.7 total weight)
5. **Safety checks are too aggressive** — forbidding common productivity tools (calendar_create, todo_create) causes false zero scores
6. **Reference solution uses tools not available to the agent**
7. **Temporal inconsistency** — dates in prompt vs fixtures don't align
