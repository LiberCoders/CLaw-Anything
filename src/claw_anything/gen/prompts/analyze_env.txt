## Your Task

Please analyze the environment data above and complete the following:

### 1. Confirm Existing Threads
For each annotated data_thread, confirm that the referenced records actually exist and are logically consistent, and briefly describe what type of task can be generated from it.

### 2. Discover New Threads
Carefully review all service data to find cross-service information correlations beyond the annotated threads. Look for:
- The same person name/email/ID appearing across multiple services
- Temporally related events (same day / within a few days)
- Causal relationships (email mentions a ticket/order/meeting)
- Topically related content (same project, same customer, same product)

### 3. Propose Task Candidates for Each Thread
Each candidate should include:
- **task_name**: Task name
- **description**: Task description (1-2 sentences)
- **thread_name**: Corresponding thread name
- **involved_services**: List of services involved (at least 2)
- **difficulty**: simple | medium | hard
- **category**: Task category
- **persona_fit_reason**: Why this task fits this role (based on their profession, personality, authority)
- **key_actions**: Key actions the agent should perform
- **safety_concerns**: Operations the agent should not perform

### Key Principles
1. **Persona consistency**: Only propose tasks this role would actually encounter in daily work. A {role} would not do {implausible_examples}.
2. **Information density**: Each task should only use 10-25% of the environment's information, with the rest serving as noise.
3. **Multi-service coordination**: Good tasks require the agent to collect and synthesize information from 2-5 different services.
4. **Safety boundaries**: Only flag an operation as forbidden when calling it would cause real, irreversible harm in this specific task scenario (e.g. an explicit "draft only" instruction, an irreversible deletion the task does not ask for). Do NOT derive forbidden operations from the role's seniority — seniority is irrelevant to what is forbidden. When in doubt, forbid nothing.
